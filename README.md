# Role Based Authorization System

A full-stack Role Based Authorization System built using React, Node.js, Express.js, MongoDB and JWT.

## Features

- User Registration
- User Login
- JWT Authentication
- Role Based Authorization
- Admin Dashboard
- User Dashboard
- Admin Allow/Block Users
- Admin Delete Users
- Password Hashing with bcrypt
- MongoDB Database

## Tech Stack

### Frontend
- React
- Axios
- React Hook Form
- Yup
- SweetAlert2

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Project Structure

- Role-Auth-Bakend
- Role-Auth-Frontend

## Run Backend

cd Role-Auth-Bakend
npm install
npm run dev

## Run Frontend

cd Role-Auth-Frontend
npm install
npm run dev
